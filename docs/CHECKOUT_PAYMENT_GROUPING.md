# Checkout Payment Grouping - Compify

Patch ini merapikan metode pembayaran di checkout dengan kategori.

## Kategori

- E-Wallet & QRIS
  - QRIS
  - GoPay
  - ShopeePay
  - DANA

- Virtual Account / Transfer
  - BCA Virtual Account
  - BNI Virtual Account
  - BRI Virtual Account
  - Mandiri Bill Payment
  - Permata Virtual Account

- Kartu Kredit / Debit
  - Kartu Kredit / Debit via Midtrans

- Retail / Minimarket
  - Indomaret
  - Alfamart

## Catatan

Semua channel Midtrans tetap memakai Midtrans Snap di backend.
Grouping ini hanya untuk membuat checkout lebih rapi dan mudah dipahami user.
